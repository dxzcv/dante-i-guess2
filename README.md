# Dante

**Dante** is a desktop pet and AI assistant for Windows 10 and 11. You will be able to talk to Dante through a chat window or activate voice interaction by saying **“Dante.”** The goal is to make everyday desktop tasks, such as opening an app, feel like a conversation.

> **Project status:** Early development.

## Planned features

- **Desktop pet:** An assistant that lives on your desktop.
- **Text and voice interaction:** Use the chat window or say “Dante” to start a voice request.
- **Windows app launching:** Ask Dante to open installed apps and programs on Windows 10 or 11.
- **Your choice of AI model:** Supply your own API key and use a supported model from the GPT, Claude, DeepSeek, or Qwen families.
- **Installer:** A Windows installer is planned for future releases.
